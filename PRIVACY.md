# DualPage 隐私政策 (Privacy Policy)

最后更新日期：2026-11-27

DualPage 是一款纯前端、零服务器的浏览器翻译扩展，高度重视您的隐私：

1. **不收集个人数据**：本扩展不会收集、记录、存储或上传您的浏览历史、身份信息、账号凭据或网页 Cookie。
2. **本地存储配置**：您的翻译偏好、自定义术语表、自动翻译网站列表以及自行填写的第三方 API Key 仅保存在您本机浏览器的存储空间（`chrome.storage`）中，不会发送至任何开发者服务器。
3. **翻译请求直连**：仅在您主动开启网页翻译、划词翻译或点击测试连接时，本扩展才会将待翻译的文本直接从您的浏览器发送至您所选择的翻译服务提供商（如微软翻译、Google 翻译、Pollinations AI 或您自行配置的 AI API 接口）以获取译文。
4. **无广告与追踪**：本扩展不包含任何广告、第三方统计 SDK 或用户行为追踪代码。

# Privacy Policy (English)

Last updated: 2026-11-27

DualPage is a zero-server, client-side browser translation extension designed with privacy first:

1. **No Personal Data Collection**: DualPage does not collect, log, sell, or transmit your browsing history, personal identity, or cookies.
2. **Local-Only Settings & Keys**: All preferences, custom glossaries, domain lists, and user-provided API keys are stored strictly inside your local browser storage (`chrome.storage`) and are never sent to any developer-owned server.
3. **Direct Translation Requests**: Only when you explicitly trigger translation, the selected text or visible page text is sent directly from your browser to the translation provider you chose (e.g., Microsoft Translate, Google Translate, Pollinations AI, or your custom OpenAI-compatible/Gemini API endpoint).
4. **No Ads or Analytics**: DualPage contains zero advertisements, trackers, or third-party analytics.
