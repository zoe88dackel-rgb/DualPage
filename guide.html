怎么用

整页翻译Alt + T / 点悬浮球
在任意外语网页按下 Alt + T 或点右下角悬浮球即可开始翻译，向下滚动时新出现的内容会自动跟翻；再点一次立刻还原原文。
划词翻译鼠标选中任意句子
不想翻整页时，直接划选一段外语。点「划词翻译」会弹出小卡片（可复制和朗读），点「沉浸对照」会把这一段的译文直接插在原文下面。
悬浮球与自动翻译按住拖动 / 点 ⋯
悬浮球可以拖到屏幕任意位置，贴边会自动吸附并跨页记住位置。点右侧 ⋯ 可以切双语模式、隐藏悬浮球，或把常去的网站设为「打开即自动翻译」。

几个细节

不用先填 Key，也能换自己的 AI

默认内置微软翻译、开源免费 AI 和 Google 翻译，装好就能用。想换更准的大模型，可以进设置页填智谱、硅基流动、DeepSeek、Gemini 或任意 OpenAI 兼容接口，每个平台的 Key 分开保存。

去配置翻译引擎

纯本地运行，不经过中间服务器

没有后端，不建账号，不收集浏览记录和 Cookie。你的 Key、白名单和术语表都只存在自己浏览器里，翻译请求直接发给所选服务商。

常用页面越用越快

首屏最先看到的 12 段优先出字，后面 5 路并发处理；翻过的内容会缓存在本地硬盘（最多 5,000 条，不到 1 MB，不占显卡），常逛的后台菜单切页直接出字。

用 Excel 维护行业术语

遇到固定专有名词总翻不对，可以在设置页逐条添加，或者下载 CSV 模板用 Excel 填好后一键导入，免费引擎和 AI 引擎都会优先按你的词表来翻。

本地安装

  1. 01
    打开浏览器扩展管理页，打开右上角的「开发者模式」开关。
  2. 02
    加载扩展目录：点击「加载已解压的扩展程序」，选择包含 manifest.json 的文件夹。
  3. 03
    直接开始用：打开任意外语网页，按 Alt + T 或点右下角悬浮球即可，已经开着的标签页也不用刷新。

常见问题

装完必须配置 API Key 吗？

不用。默认选的是免 Key 免费引擎，直接点翻译就行；只有想换自己的大模型时才需要去设置页填 Key。

为什么在 edge:// 或扩展商店页面点翻译没反应？

浏览器不允许任何扩展在内置系统页和应用商店页注入脚本，切到任意普通 https:// 网页即可正常使用。

怎么把词库和配置发给同事？

在「API 与词库设置」右上角点「导出配置」保存成 JSON 文件，同事那边点「导入配置」即可同步。
