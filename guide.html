常见问题。

为什么浏览器内置页面（如 chrome://）无法翻译？
出于安全限制，Chrome 与 Edge 不允许任何扩展向 chrome://、edge:// 或应用商店页面注入脚本。所有常规 http:// 与 https:// 网页均可正常实时翻译。
如何让常用外语网站每次打开都自动翻译？
打开目标网站后，点击右上角 DualPage 图标（或悬浮球右侧的 ⋯），打开「始终自动翻译当前网站」开关即可，也可以在 API 配置页统一管理白名单。
想发给团队同事一起用，怎么分享最方便？
直接把整个 web-translator-ext 文件夹压缩发给同事，解压后按上方三步加载即可永久免费使用，无需注册任何付费开发者账号。
