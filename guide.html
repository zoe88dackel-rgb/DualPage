新手常见问题与更新记录。

刚装好扩展，必须要先去申请 API Key 才能用吗？
完全不需要。DualPage 默认内置了免 Key 高速翻译引擎，装好后直接打开任何外语网页点「翻译」悬浮球或按 Alt + T 就能立刻使用。
为什么在浏览器设置页或扩展商店里点翻译没反应？
出于浏览器底层安全限制，所有扩展均不允许在 edge://、chrome:// 或官方扩展商店页面内运行脚本。请切换到任意常规 https:// 外语网站测试。
悬浮球挡住了网页右下角的按钮怎么办？
鼠标左键按住悬浮球即可自由拖到屏幕任意高度，松手后靠近左右边缘会自动贴边停靠并跨网页记住位置；也可以点悬浮球右侧的 ⋯ 选择隐藏悬浮球，单靠 Alt + T 快捷键控制。
怎么把配好的接口和术语表同步给团队同事？
点击右上角「配置 API 与词库」，在配置中心顶部点击「导出配置」生成 JSON 文件发给同事，同事点击「导入配置」即可一秒同步全部设置与词表。
